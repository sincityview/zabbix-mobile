# Android-версия (Kotlin + Jetpack Compose)

Замена Go/Fyne-сборки. Лежит рядом с Go-версией; ветка разработки — `dev`,
после паритета сливаем в `master`.

## Что уже работает

- экран настроек: URL сервера, токен, флаг самоподписанного сертификата,
  лимит отображения проблем (1…10000), интервал автообновления (10…3600 с),
  предупреждение про `http://`; действия — значками в шапке (закрыть,
  проверить подключение, сохранить);
- список проблем: `problem.get` + `trigger.get`, цветная полоса важности,
  отметка восстановленных, детали по тапу, ошибка и повтор;
- счётчик в шапке — `показано/всего` (например `100/182`); плюс в конце
  означает, что проблем больше, чем просматривается за один опрос (2000);
  по нажатию на счётчик открывается выбор показа: «По умолчанию» (все
  проблемы) или конкретная важность (Disaster…Не классифицирована) — тогда в
  списке остаются только такие проблемы, а счётчик считает их же; выбор
  запоминается;
  кнопки «обновить» и «настройки» — значки;
- обновление списка: кнопкой, жестом «потянуть вниз» и автоматически с
  интервалом из настроек — только когда приложение на переднем плане;
- настройки в приватных `SharedPreferences`, `allowBackup=false`.

Параметры запросов повторяют страницу «Problems» в Zabbix
(`CScreenProblem::getData`): `suppressed=false`, `symptom=false`, `recent=true`,
а для триггеров `monitored=true` и `skipDependent=true`. Именно последние два
давали «дубликаты» в Go-версии: на боевом сервере из 162 проблем страница
показывает 150 — 2 проблемы выключенного хоста и 10 проблем зависимых
триггеров, у которых мастер уже в состоянии проблемы.

## Сборка

```bash
cd android
./gradlew testDebugUnitTest lint assembleRelease
```

APK: `android/app/build/outputs/apk/release/app-release.apk`.
Локально нужен Android SDK (`local.properties` с `sdk.dir=...` или `ANDROID_HOME`)
и JDK 17+ (в CI — 21).

Юнит-тесты (`app/src/test/...`) проверяют без Android:

- `ZabbixUrlTest` — нормализация адреса (те же случаи, что в Go-версии);
- `ZabbixApiTest` — параметры запросов, дедупликация по триггеру, отбрасывание
  проблем неотслеживаемых триггеров, отметка восстановленных, ошибка API,
  наличие `jsonrpc` в теле запроса;
- `ZabbixTimeTest` — формат времени.

### Чем проверено

- 9 юнит-тестов прогнаны на JVM (`kotlinc` + JUnit, без Android SDK);
- клиент целиком прогнан против боевого Zabbix 7.4: список совпал со страницей
  «Problems» — 245 против 245 при `limit=5000`. При этом API отдаёт 338
  проблем: 93 из них Zabbix не показывает (проблемы зависимых триггеров и
  выключенных хостов) — именно они и были «дубликатами» в Go-версии;
- заодно найден и исправлен реальный баг: `kotlinx.serialization` по умолчанию
  не сериализует поля, равные значению по умолчанию, и запрос уходил без
  `"jsonrpc": "2.0"` — сервер отвечал «the parameter jsonrpc is missing».
  Теперь `encodeDefaults = true`, на это есть тест-регрессия.

Лимит отображения (`100` по умолчанию) режет уже полученный список, поэтому
`всего` в счётчике честное: за один опрос просматривается до 2000 проблем.

## CI

`.github/workflows/android.yml` — отдельный воркфлоу, Go-сборка не тронута:

- `pull_request` / `workflow_dispatch` — `lint` + `testDebugUnitTest` +
  `assembleRelease`, APK уходит артефактом `zabbix-monitor-apk`;
- `push` тега `v*` — то же самое; вложение APK в релиз включается переменной
  репозитория `ANDROID_RELEASE=true` (пока релиз делает Go-воркфлоу).

Секреты — те же, что уже есть в репозитории:

| секрет | назначение |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | keystore в base64 |
| `ANDROID_KEY_ALIAS` | alias ключа |
| `ANDROID_KEYSTORE_PASSWORD` | пароль keystore и ключа |

Без `ANDROID_KEYSTORE_BASE64` release подпишется debug-ключом — сборка в PR не падает.

## Что сознательно не сделано в первой версии

- R8/сжатие выключено (`app/build.gradle.kts`): сначала нужен прогон на
  устройстве, чтобы сжатие не сломало сериализацию незаметно.
- Нет входа по логину/паролю (только токен), нет настроек интервала и лимита,
  нет кеша последнего ответа и уведомлений о новых проблемах.
- Динамическая тема следует системной; ручной переключатель не нужен —
  в Go-версии он был вынужденным (fyne не умел следовать системе).

## Отличия от Go-версии, заложенные заранее

- `applicationId` тот же — `com.zabbix.android.monitor`, поэтому при подписи
  тем же ключом приложение обновится поверх установленного, а не встанет вторым.
- `minSdk 26` (Android 8.0); правится одной строкой в `app/build.gradle.kts`.
- Язык интерфейса берётся из системного (ru/en в ресурсах).
