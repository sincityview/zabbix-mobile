####  Zabbix Android API Client 
------

**Версия App**
```text
v0.8.0
```

**Версия Go**
```text
1.24.6
```

**Сборка Fyne**
```text
go install github.com/fyne-io/fyne-cross@latest

fyne-cross android -app-version 0.8.0 -app-id com.zabbix.android.monitor -icon icon.png \
  -tags no_emoji -arch arm64
```

**Важно про `-ldflags` у fyne-cross.** Linker-флаги fyne-cross передаёт не
аргументом, а через переменную `GOFLAGS`, и оборачивает значение в кавычки, если
в нём есть `=` (`AppendEnv` в `internal/command/docker.go`). Поэтому:

- `-ldflags "-s -w"` **ломает сборку** — многословное значение схлопывается в
  один аргумент (`go: parsing $GOFLAGS: unknown flag ...` или
  `flag provided but not defined: -ldflags`);
- допустим только один токен, например `-ldflags "-s"`;
- по умолчанию strip уже делает сам fyne: fyne-cross вызывает
  `fyne package -release`, а тот добавляет `-ldflags -w` и `-trimpath`
  (см. `cmd/fyne/internal/mobile/build.go`). Поэтому флаги вообще не нужны.

Если нужен максимально маленький APK, можно перекрыть это поведение:
`-no-strip-debug -ldflags "-s"` — экономит ещё ~2.4 МБ (символьная таблица), но
сборка пойдёт без `release`-режима fyne.

**Приложение для Android**
- Нужно сгенерировать на стороне сервера Token (или использовать логин/пароль)
- Можно получать текущие проблемы
- Есть проверка подключения прямо в окне настроек
- Кеш последнего ответа: при запуске данные видны сразу, без ожидания сети
- Карточка триггера — всегда три строки фиксированной высоты (время, хост,
  проблема): длинные значения обрезаются посередине с сохранением значимого
  хвоста, а полный текст открывается тапом по карточке

<br>

**Где хранятся настройки**

Настройки пишутся в приватный каталог приложения:

```text
/data/user/0/com.zabbix.android.monitor/files/fyne/settings.json
/data/user/0/com.zabbix.android.monitor/files/fyne/settings.json.bak
/data/user/0/com.zabbix.android.monitor/files/fyne/last_problems.json
```

- запись атомарная: `tmp` → `fsync` → `rename` → `fsync` каталога,
  поэтому обрыв питания или убийство процесса не оставляют пустой файл;
- предыдущая версия всегда сохраняется в `settings.json.bak` и читается, если
  основной файл повреждён;
- в окне настроек внизу показан путь к файлу и пометка, если данные были
  восстановлены из резервной копии;
- настройки старой версии из `preferences.json` переносятся автоматически при
  первом запуске и продолжают дублироваться туда как зеркало;
- в `last_problems.json` нет секретов: вместо токена хранится необратимый
  отпечаток конфигурации, поэтому кеш чужого сервера не показывается.

При переустановке APK с другой подписью Android стирает данные приложения —
это единственный случай, когда настройки теряются навсегда (используйте один и
тот же keystore для всех релизов).

<br>

**Безопасность**

- файлы настроек создаются с правами `0600`, каталог — `0700`;
- токен и пароль хранятся в типе `Secret`: маскируются в логах и в `fmt`
  (`%v`, `%+v`, `%#v`), но полноценно сериализуются в файл;
- `Authorization` не уходит на другой хост: редиректы разрешены только в
  пределах исходного хоста (иначе — ошибка);
- минимальная версия TLS — 1.2, проверка сертификата включена; отключение
  («Самоподписанный сертификат») — осознанный выбор пользователя;
- если в URL вставлены учётные данные (`https://user:pass@host`), они
  переносятся в поля и вырезаются из адреса, чтобы не попасть в логи;
- при `http://` интерфейс предупреждает, что токен пойдёт открытым текстом;
- кнопка «Сбросить настройки» удаляет адрес, токен, пароль, зеркало в
  `preferences.json` и кеш проблем с устройства.

Токен хранится в открытом виде внутри приватного каталога приложения: Android
Keystore через Fyne недоступен без cgo/JNI, поэтому защита — это песочница ОС,
права `0600` и кнопка сброса. Для мониторинга рекомендуется выпускать токены с
ограниченным сроком жизни.

<br>

**Оптимизации**

- один переиспользуемый HTTP-клиент: keep-alive и HTTP/2, без нового TLS
  handshake на каждый опрос;
- кеш «триггер → хост» на 10 минут: обычно один запрос вместо двух;
- ретраи только для сетевых сбоев и 5xx/429, ошибки API и 4xx возвращаются сразу;
- автообновление на таймере (смена интервала применяется мгновенно) и полная
  остановка опроса, когда приложение в фоне;
- список не перерисовывается, если ответ не изменился;
- сборка: `-ldflags "-s -w -buildid="` и `-tags no_emoji` (убирает встроенный
  эмодзи-шрифт, ~4 МБ). Если в названиях триггеров важны эмодзи — уберите тег.
